Issues — Resolve Panel Redesign

Panel saat ini cuma 420px (kanan), tombol-tombol pilihan terpotong, dan extra input field (Lokasi / Alasan detail) hampir tidak terlihat. Padahal "resolve" ini core action user. Dua varian di bawah membuat panel jauh lebih dominant + grouping reason supaya gampang dipilih.

Masalah saat ini: panel resolve kanan 420px → button label terpotong ("Tugas Lapangan", "Pulang Lebih Awal" cut), extra input field tidak prominent atau hilang visually, user merasa core action ditempatkan di tempat sempit.

Variant A1 — Modal Dialog Recommended

Klik issue → modal terpusat (720px) muncul dengan dim overlay. List masih ada di belakang (transparent), tapi fokus user pure ke resolve. Reason cards di-group jadi 4 kategori (Tugas, Izin/Cuti, Telat/Lupa, Lain). Card yang butuh input tambahan ditandai ✏️. Begitu di-pilih, field input langsung muncul prominent dengan border accent.

Karakteristik A1 (Modal):
  • Modal 720px lebar — semua label reason kebaca utuh, tidak terpotong
  • 4 kategori grouping → user lebih cepat scan ke kategori yang tepat
  • Card yang butuh input ditandai ✏️; saat di-pilih, field muncul dengan accent border merah-pink
  • Live preview "akan tampil di Main DB sebagai: ..." → user yakin hasilnya benar sebelum Save
  • Save button disabled sampai (a) reason di-pilih DAN (b) extra input terisi (kalau perlu)
  • Trade-off: hide list sementara saat resolve. Tapi user fokusnya satu issue saja.

Variant A2 — Expanded Split Panel (50/50)

Klik issue → list shrink ke 50%, resolve panel jadi 50%. Reason cards susun 2 kolom (lebih sempit dari modal tapi tetap >> dari 420px panel sekarang). User bisa lihat daftar issue lain saat resolve.

Trade-off ringkas — Loading

VarianPlusMinusCocok untuk
L1 Modal Paling jelas. User pasti sadar. Bisa muat detail (filename, jumlah baris) Paling intrusif. Konten ketutup. Kalau operasi cuma 1-2 detik agak overkill Heavy ops (Restore, Backup, Import banyak baris)
L2 Top Strip Konten tetap visible. Mirip pola browser loading Kurang dramatis — user mungkin tetap coba klik (tapi tetap di-block) Medium ops (Export PDF, Main DB load)
L3 Bottom Sheet Modern. Hover di atas konten tanpa sembunyiin. Cukup prominent Lebih banyak kerja implementasinya (animasi slide-up). Ada risk content geser Medium ops kalau mau tampilan modern

Success Toast (notifikasi berhasil — kanan atas, non-blocking)

Muncul setelah operasi sukses. Tidak block clicks. Auto-dismiss setelah 3-4 detik atau bisa di-close manual. Sesuai permintaanmu: kanan atas + transparan.

Trade-off ringkas — Toast

VarianPlusMinusCocok untuk
T1 Frosted Glass Paling sesuai keinginan "transparan". Look premium Backdrop-filter blur di Flet/Flutter butuh `ft.BackdropFilter` — feasible tapi sedikit lebih ribet Kalau mau kesan modern
T2 Translucent Solid Reliable di semua kondisi background. Tetap "transparan-ish" (opacity 82%). Mudah implement Kurang fancy dibanding T1 Pilihan paling aman untuk readability
T3 Minimal Pill Sangat subtle. Cocok kalau ada banyak notif berurutan Mudah miss kalau user lagi fokus ke konten utama Notif yang sangat frequent

Skenario lengkap — Import .xls (rekomendasi: L1 + T1 atau L1 + T2)

Step 1 · User klik
Klik "✅ Import"
User memilih file dan klik tombol Import.
Step 2 · Loading muncul
L1 modal aktif (~2 detik)
Modal "Sedang import... 247 baris" muncul. Sidebar tidak responsif. User tidak bisa nav.
Step 3 · Selesai
Modal hilang + toast muncul
Toast kanan atas muncul: "✅ Import berhasil · 247 new · 0 conflict". Auto-dismiss 4 detik.
Catatan teknis (Flet 0.25.2): Semua varian feasible. T1 (frosted glass) butuh ft.Container(blur=...) atau widget ft.BackdropFilter — sedikit lebih banyak boilerplate dibanding T2 yang cukup pakai bgcolor dengan alpha channel. L3 butuh ft.AnimatedSwitcher untuk slide-up. L1 paling lurus pakai page.overlay.append(Container).

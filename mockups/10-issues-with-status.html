Issues — List with Status + Resolve Modal

Final design per feedback: AI recommendation pindah dari list ke dalam modal. List sekarang punya status badge "Pending" (atas) atau "Resolved" (bawah), sehingga user bisa trace history resolve issue.

1️⃣ Issue List — Dengan Status Badge + Sorting

Pending issues di atas (yang masih perlu di-handle), Resolved issues di bawah (sudah ditangani). Each row punya status badge yang jelas. Yang Resolved sedikit di-dim (opacity 78%) supaya secara visual user tau yang utama itu Pending. Klik issue Resolved → tetap bisa buka modal untuk re-edit.

  • Section divider antara Pending dan Resolved + count chip di sebelah label
  • Pending row: AKSEN MERAH (border-left + bg merah-soft) → urgensi visual jelas

  • AI banner — pindah ke modal, tampil prominent dengan ikon biru di atas reason categories
  • Saat user buka issue YANG SUDAH RESOLVED → modal muncul dengan reason card-nya pre-selected, plus extra input pre-filled. Footer ada tombol "🗑 Delete Resolution" (kanan) buat unresolve kalau salah pilih
